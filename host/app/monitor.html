工作方式

电脑摄像头帧缩放到 320×240 后经 HTTP 送到开发板，由 ARM 或 FPGA 滤波；电脑麦克风以 48 kHz PCM 分块送入同一套 255 抽头 FIR。处理后的画面回到网页并送到 HDMI；滤波后的 PCM 回到网页，由电脑扬声器或耳机播放。

这是低帧率单路演示链路，不是多路并行监控。页面帧率包含摄像头采集、HTTP、JPEG、滤波和显示；声音有采集/网络/分块处理延迟，不代表端到端声学延迟。

打开方式

在演示电脑的项目目录运行：

python host/deploy/tools/camera_proxy.py --board http://<板卡IP>:8080

保持窗口运行，浏览器打开 http://localhost:8765/monitor，允许摄像头和麦克风权限。

代理只监听 127.0.0.1，把页面和 API 转发到开发板；不要在板卡 IP 的 8080 页面直接点启动，否则浏览器会以“非安全来源”拒绝摄像头/麦克风。

运行提示

启动前先停止第一页的歌曲播放、视频播放和性能测量，避免共享 DMA 冲突。若画面掉帧或声音断续：关闭其他占用 CPU 的程序、降低摄像头分辨率、换用 5 GHz/有线网络，并确认板卡没有同时跑其他作品服务。

HDMI 的 BTN3 可在“实时画面”和“音频波形/频谱”之间切换。停止后摄像头、麦克风和音频上下文都会释放。

电脑负责摄像头/麦克风采集与显示；PYNQ-Z2 负责 ARM/FPGA 滤波、HDMI 与板载状态。
