# 指标汇总表与原始证据

## 1. 目录内容

| 路径 | 内容 |
|---|---|
| `metrics.csv` | 指标汇总表，表头为赛题 3.2.5.2 规定格式，一行一项指标 |
| `logs/` | 每项指标对应的**原始日志**（板端导出的 JSON / CSV，未经转述） |
| `scripts/` | 可在提交环境中重跑的测试与校验脚本 |
| `evidence/` | 证据截图（当前只有板端页面截图，说明见 §4） |

`metrics.csv` 中"证据文件"一列指向的就是 `logs/` 里的文件，路径相对仓库根目录。

## 2. 数值从哪来

**全部数值来自 `logs/` 里的原始文件，没有任何一项是从报告里转抄的。**
每个数值都可以用 `scripts/` 里的脚本重新测一遍覆盖：

| 指标类别 | 重跑方式 |
|---|---|
| 视频/音频单次调用耗时与误差 | 板端执行 `python host/deploy/check_video_effects_board.py --host <board-ip>`；音频基准由 `host/app/audio_benchmark.py` 触发（网页「音频测量」按钮） |
| 逐像素 / 逐样本误差 | 同上；黄金参考比对用 `scripts/compare_golden.py --host <board-ip>` |
| 完整播放帧率 / CPU / 丢帧 / 采样对账 | 网页「分轮测试」按钮，或 `scripts/check_video_effects_board.py` 的两轮完整播放；汇总用 `scripts/summarize_board_reports.py` |
| 资源与时序（LUT/FF/BRAM/DSP/WNS/WHS） | 主机侧 `scripts/check_ppa.py --build-dir fpga/src/build/video_effects_output`，或直接看 `fpga/report/timing.rpt`、`utilization.rpt` |
| RTL 仿真通过率 | 按 `README.md` §4.2 跑 `xsim`，输出 24 组用例的 PASS/FAIL |

## 3. 口径警告（重要）

不同表格之间的数字**不能跨口径相比**，这是本作品刻意保留的：

| 口径 | 含 | 不含 |
|---|---|---|
| 单滤波调用（视频/图片） | FPGA 侧：边界填充、原生打包、DMA、解包；ARM 侧：OpenCV 调用与内存分配 | 解码、缩放、合成、HDMI、音频 |
| 完整播放 | 解码、帧准备、滤波、合成、HDMI 写入、音频推进 | 显示器/扬声器物理时延 |
| 音频后端基准 | ARM：分配 + ctypes + C FIR；FPGA：寄存器配置 + 缓存维护 + DMA + 轮询 + 回拷 | 文件 IO、播放、混音、显示 |

因此"边缘提取单滤波 2.79×"**不等于**"整段播放 2.79×"——完整播放还受解码、合成与 HDMI 刷新限制，
这也是显示帧率只有 7–8 FPS 的原因。两个口径分开报告，不合并成一个"加速比"。

## 4. 关于示波器 / 逻辑分析仪截图

赛题要求"延迟与抖动类指标的波形、示波器或逻辑分析仪截图"。本作品**没有提供这类截图**，原因如下：

- 作品测量的是**软件可观测的时间点**（函数进入/返回、DMA 提交/完成、HDMI 提交、已播采样计数），
  这些时间戳由板端程序自己记录，本身就带微秒级精度与可复现的判据，不需要外部探头。
- 音频"抖动"的真实度量是**硬件 FIFO 的欠载次数与已播采样数对账**（本轮 30 秒：`submitted=played=1440127`、`underruns=0`），
  这比示波器看单个 I2S 帧更能说明"整段会话没丢样"。
- 板卡上并未引出可供探头测量的测试点，也无法在不破坏时序的前提下加测量点；
  为避免"用示意图冒充证据"，此处如实标注为**未提供的证据**，替代证据为 `logs/` 中的原始 JSON/CSV 与 `evidence/` 中的板端截图。

如果评审要求外部仪器证据，需要在板卡 Pmod 口引出 I2S 位时钟与帧同步后重做测量，这属于后续工作。

## 5. 测量条件一列写的是什么

`metrics.csv` 的"测量条件"列按赛题要求写明了：**硬件型号**（PYNQ-Z2 / XC7Z020）、
**软件版本**（Vivado 2024.1 / Vitis HLS 2024.1 / PYNQ 3.1）、**输入规格**（320×180 BGR888 或 4096 样本 PCM16）、
**数值精度**（音频 Q1.15 定点、视频 8 位无符号 + 16 位中间量）、**FPGA 时钟频率**（100 MHz 固定）
与**功耗模式**（板卡常压供电、无 DVFS 调频）。
