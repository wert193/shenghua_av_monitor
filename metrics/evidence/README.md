## 未提供的证据（如实标注）

赛题 3.2.5.2 要求"延迟与抖动类指标的波形、示波器或逻辑分析仪截图"。本作品**没有提供**这类截图，原因已在
[`../README.md`](../README.md) §4 说明，摘要如下：

1. 本作品的延迟类指标由**板端时间戳**（函数进入/返回、DMA 提交/完成、HDMI 提交、已播采样计数）测量，
   不是靠外部探头；这些时间戳随原始 JSON 一起提交，可复核。
2. 音频抖动的真实判据是**硬件 FIFO 的欠载次数与已播采样数对账**（30 秒会话：`submitted=played=1440127`、`underruns=0`），
   比示波器看单个 I2S 帧更能说明整段会话没丢样。
3. 板卡未引出可供探头测量的测试点；为避免用示意图冒充证据，此处保留空缺。

若评审必须要求外部仪器证据，需要在 Pmod 口引出 I2S 位时钟与帧同步后重做测量，属后续工作。
