# ① 提示词工作流

**适用场景**：与模型协作完成嵌入式/FPGA 工程——从"我想做出什么效果"到"可复现的交付包"。
**使用方法**：把下面的模板按阶段使用；每个阶段的输出必须落到一个**可执行物**（脚本、断言、报告文件）上，再进入下一阶段。
**已验证效果**：本工程的 20 条自我纠错轨迹、四道门禁与全部交付文档都由这套提示词产出；它也是"模型给出但被实测推翻"的判断被及时拦下的原因。
**失效条件**：没有可运行环境（无板卡、无仿真器）时，这套流程只能用于方案推演，**不能产出技术结论**。

---

## 1. 四阶段提示词

### 阶段 A：需求翻译与口径冻结

```text
我要做的是：<一句话人话目标>。
这次对比只允许改 <变量>，其它全部固定：<输入 / 算法 / 尺寸 / 边界 / 参数 / 顺序>。
请先不要写代码，做三件事：
1) 把目标翻译成 3–5 条可测指标，每条给出单位与通过条件；
2) 对每个指标写一句话的"耗时从哪到哪、包含什么、不含什么"；
3) 列出会污染这个对比的因素，并给出固定它们的办法。
```

要点：**先冻结口径再写实现**。本工程里"FPGA 时间包含边界填充/打包/DMA/回拷""CPU 是整板占用"这两句话，就是这一步产出的，后来被原样写进 JSON 的 `scope` 字段。

### 阶段 B：生成可执行物（脚本 / RTL / 测试向量）

```text
按上面的口径实现 <功能>。要求：
1) 每个函数/模块都要有输入合法性检查，错误信息要能定位到具体参数；
2) 所有等待/轮询必须有截止时间，超时打印可诊断状态；
3) 同时给出测试向量生成脚本，向量必须包含退化用例：<1×1 / 1×N / N×1 / 全黑全白 / 饱和 / 边界 / 背压 / 连续帧>；
4) 给出一个能打印 PASS/FAIL 的检查入口，而不是只给我结果数字。
```

要点：**断言比实现更值钱**。本工程的 testbench 覆盖 24 组用例（含 AXI 背压与音频旁路），板端脚本直接断言 `played == 1440127` 与 `underruns == 0`。

### 阶段 C：反例与反驳（对"加速/已解决"类结论强制使用）

```text
你刚才给出了"<某结论>"。请先不要为它辩护：
1) 列出三条能推翻它的检查，并说明每条怎么执行；
2) 指出这个结论里可能混入的口径差异（是否含传输、是否含解码/显示、是否同一参考实现、是否同一尺寸）；
3) 给出一个最小复现实验，能区分"结论正确"和"统计噪声"。
```

要点：本工程正是靠这一步拦下了"FPGA 更快 2 倍""整体加速"这类表述，改为"单滤波调用口径下 2.79×，整段播放仍约 8 FPS"。

### 阶段 D：交付自检与文档

```text
请把这个版本的交付包做一次自检，输出一份检查清单：
1) 必需文件是否齐全（源码 / 构建脚本 / 报告 / 数据 / 复现说明）；
2) 是否含隐私或不可公开内容（本机绝对路径、主机名、固定 IP、用户名、媒体文件）；
3) 单文件与总体积是否超限；
4) 上一版声明"未验证"的条目，逐条给出现在的状态；
5) 给我一段 100 字以内的"本版能力/本版边界"说明，用于对外材料。
```

要点：把"未验证项"当成**版本状态**逐版更新，而不是每次重写。

## 2. 常用小提示词（可直接复制）

| 目的 | 提示词 |
|---|---|
| 让模型先给检查项 | "在写实现之前，先给我一份这个功能最容易出错的 10 条检查清单。" |
| 强制分口径 | "把所有性能数字按口径分组，每组一句话说明包含什么；不同组之间不要给我比值。" |
| 让模型承认不确定 | "这份结论里哪些是实测、哪些是推理、哪些是猜测？用三栏列出。" |
| 排障分层 | "给我一个从物理层到应用层的分层排查顺序，每层给出一个一分钟内能做完的判定动作。" |
| 生成退化用例 | "为这个 3×3 邻域算子列出退化输入，并为每个写一条最短测试。" |
| 统一参考实现 | "把图片与视频两条路径的参考实现合并成一个函数，并给出验证合并后结论未变的方法。" |
| 复现说明 | "写一份从零开始的复现步骤，要求每步都有判定条件（不通过就不要继续）。" |

## 3. 与模型协作时的三条硬规则

1. **不许删除对"加速方案"不利的成本**。要么保留，要么给出同口径的前后对比（本工程把 FPGA 平滑的 26.966 → 11.582 ms 全过程保留下来，即使最终仍比 ARM 慢）。
2. **逐字对话不作为技术证据**。技术结论只认"现象 → 根因 → 修正 → 可复核证据"这条链。
3. **未上板不得写成已验证**。本工程有两处历史故障（整板网络不可达、HDMI 无信号）根因至今未定位，文档里如实标注，而不是写成已解决。
